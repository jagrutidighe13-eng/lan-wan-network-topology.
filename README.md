# LAN and WAN Network Topology

## Project Overview
This project demonstrates the design and configuration of a basic LAN and WAN network using Cisco Packet Tracer.

## Tools Used
- Cisco Packet Tracer
- Networking concepts
- LAN and WAN

## Network Components
- Routers
- Switches
- PCs
- Network connections

## Project Objectives
- Understand LAN and WAN topology
- Configure network devices
- Establish communication between different networks
- Understand basic IP addressing and routing
